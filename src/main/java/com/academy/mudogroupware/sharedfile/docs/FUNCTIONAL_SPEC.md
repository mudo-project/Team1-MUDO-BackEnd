# 공유파일 기능명세서

## 공통 전제

- 이 배포 단위의 Google 계정 하나를 연결하고, 직원은 학원 공용 Google 계정으로 로그인된 상태에서 Google 원본 화면을 사용한다.
- 시스템 루트 폴더 이름은 `이음 그룹웨어 - 공유파일`이며, 배포 단위당 하나만 자동 생성·보호한다.
- 시스템 루트 아래의 모든 폴더는 일반 폴더다. 첫 화면의 1단계 폴더는 UI에서 공용 자료함으로 표시할 수 있다.
- Google Drive가 파일·폴더의 원본이며, 이음 DB에는 시스템 루트 설정만 저장한다.
- 시스템 루트 하위 동명 파일·폴더는 허용하고 자동 덮어쓰지 않는다.
- 서비스와 DB가 학원별로 분리된 단일 테넌트 구조이므로, 신규 공유파일 API·UseCase는 `academyId`를 입력받아 조회·검증하지 않는다.

| 업무 | 중분류 | 권한 | 기능명 | 기능 설명 |
| --- | --- | --- | --- | --- |
| 공유파일 | 공용 폴더 초기화 | 시스템 자동 | 학원 공용 루트 폴더 생성 | Google 계정 연동 성공 후 해당 계정의 Google Drive에 학원 전용 시스템 루트 폴더를 자동 생성한다. |
| 공유파일 | 공용 폴더 초기화 | `SHAREDFILE:ROOT_MANAGE` | 공용 루트 폴더 재생성 | 최초 생성 실패 또는 Drive에서 루트 폴더 삭제가 확인된 경우 새 시스템 루트 폴더를 생성한다. 이전 계정의 파일은 자동 이전하지 않는다. |
| 공유파일 | 폴더 조회 | `SHAREDFILE:MANAGE` | 시스템 루트 목록 조회 | 공유파일 탭 진입 시 시스템 루트의 직접 하위 폴더·파일 목록을 조회한다. 자동 카테고리 폴더는 생성하지 않는다. |
| 공유파일 | 폴더 조회 | `SHAREDFILE:MANAGE` | 폴더 탐색 | 사용자가 폴더를 선택하면 해당 폴더의 직접 하위 폴더·파일만 조회한다. 전체 하위 폴더를 한 번에 조회하지 않는다. |
| 공유파일 | 폴더 조회 | `SHAREDFILE:MANAGE` | 경로 이동 | 현재 폴더부터 시스템 루트까지의 상위 경로를 표시하고, 사용자가 경로를 선택해 상위 폴더 또는 시스템 루트로 이동할 수 있다. |
| 공유파일 | 검색 | `SHAREDFILE:MANAGE` | 시스템 루트 전체 검색 | 파일명·폴더명으로 시스템 루트 전체를 검색한다. 파일/폴더 유형 필터를 지원하며, Google Drive 검색 결과 중 시스템 루트 하위 항목만 반환한다. |
| 공유파일 | 폴더 생성 | `SHAREDFILE:MANAGE` | 하위 폴더 생성 | 시스템 루트 하위의 현재 선택 폴더에 일반 하위 폴더를 생성한다. 개인 Drive 등 시스템 루트 밖에는 생성할 수 없다. |
| 공유파일 | 파일 생성 | `SHAREDFILE:MANAGE` | 로컬 파일 업로드 | 로컬 파일 한 개를 선택한 폴더에 업로드한다. 파일 형식은 제한하지 않고, 파일당 최대 100MB까지 허용한다. |
| 공유파일 | 파일 생성 | `SHAREDFILE:MANAGE` | Google Docs 생성 | 선택한 폴더에 빈 Google Docs 파일을 생성한다. 공지문, 회의록, 상담 기록지 등에 사용한다. |
| 공유파일 | 파일 생성 | `SHAREDFILE:MANAGE` | Google Sheets 생성 | 선택한 폴더에 빈 Google Sheets 파일을 생성한다. 업무 현황표, 수업자료 표 등에 사용한다. |
| 공유파일 | 파일 생성 | `SHAREDFILE:MANAGE` | Google Slides 생성 | 선택한 폴더에 빈 Google Slides 파일을 생성한다. 수업 발표자료, 학원 안내자료 등에 사용한다. |
| 공유파일 | 상세·미리보기 | `SHAREDFILE:MANAGE` | 파일·폴더 상세 조회 | 이름, 파일 유형, 수정 시각, 미리보기 가능 여부, 다운로드 가능 정보 등을 조회한다. |
| 공유파일 | 상세·미리보기 | `SHAREDFILE:MANAGE` | Google Drive 미리보기 열기 | 파일 상세에서 Google Drive 미리보기 URL을 새 탭으로 연다. Google Docs·Sheets·Slides는 Google 원본 화면으로 열린다. |
| 공유파일 | 상세·미리보기 | `SHAREDFILE:MANAGE` | 미리보기 미지원 안내 | Google Drive가 미리보기를 제공하지 않는 파일은 프론트에서 미리보기 불가와 다운로드 가능 여부를 안내한다. |
| 공유파일 | 파일 다운로드 | `SHAREDFILE:MANAGE` | 원본 파일 다운로드 | 직접 업로드한 PDF, Word, Excel, 한글, 이미지, 압축파일 등은 원본 파일 그대로 다운로드한다. |
| 공유파일 | 파일 다운로드 | `SHAREDFILE:MANAGE` | Google 파일 변환 다운로드 | Google Docs는 PDF/DOCX, Sheets는 PDF/XLSX, Slides는 PDF/PPTX 형식으로 변환해 다운로드한다. |
| 공유파일 | 파일·폴더 수정 | `SHAREDFILE:MANAGE` | 이름 변경 | 시스템 루트 하위 파일·폴더의 이름을 변경한다. 일반 업로드 파일은 확장자를 유지하고 파일명 본문만 변경한다. 시스템 루트 자체는 변경할 수 없다. |
| 공유파일 | 파일·폴더 수정 | `SHAREDFILE:MANAGE` | 이동 | 시스템 루트 하위 파일·폴더를 같은 시스템 루트 내부의 다른 폴더로 이동한다. 개인 Drive 등 외부 경로로 이동할 수 없다. |
| 공유파일 | 파일·폴더 삭제 | `SHAREDFILE:MANAGE` | 휴지통 삭제 | 선택한 파일·폴더를 Google Drive 휴지통으로 이동한다. 영구 삭제하지 않으며, 공유파일 목록에서는 제외된다. 휴지통 복원은 Google Drive에서 수행한다. |
| 공유파일 | 연동 예외 | `SHAREDFILE:MANAGE` | Google 계정 재연결 안내 | 학원 Google 계정이 미연결·만료·실패 상태이거나 `drive.file` 권한이 없으면 Drive API를 호출하지 않고 관리자에게 재연결을 안내한다. |
| 공유파일 | 연동 예외 | `SHAREDFILE:ROOT_MANAGE` | 공용 루트 복구 안내 | 시스템 루트가 생성 실패 상태이거나 실제 삭제된 경우, 일반 파일 없음 오류 대신 공용 루트 폴더 재생성 안내를 표시한다. |

## 프론트엔드 UX 범위

- 삭제 확인 모달은 프론트엔드가 제공한다. 백엔드는 확인 상태를 별도로 저장하거나 받지 않고, 확인된 삭제 요청만 처리한다.
- 업로드 진행률 패널과 백그라운드 업로드는 초기 범위에서 제외한다.
