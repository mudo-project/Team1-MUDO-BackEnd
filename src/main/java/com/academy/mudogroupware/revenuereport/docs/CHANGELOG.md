# 📚 매출 리포트(revenuereport) Changelog

## 2026-08-13 · 리포트 생성 시 알림함 연동 🔔

- 매출 리포트가 새로 생성되면 원장(ACADEMY:OWNER)에게 알림함(`/api/notifications`) 알림이 함께 갑니다. 기존 목록 화면의 안읽음 표시(`read_at`)는 그대로 유지되고, 이번 알림은 벨 아이콘 등 알림함에서도 보이게 하는 용도입니다.
- 원장 계정이 아직 없으면(부트스트랩 전 등) 조용히 건너뜁니다 — 알림 발송 실패가 리포트 생성 자체에 영향을 주지 않습니다.
