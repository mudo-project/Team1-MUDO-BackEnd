# 📚 Approval Changelog

## 2026-08-04 · 첨부파일 AI 요약(Gemini) 실제 연동 🤖

- 결재 첨부파일에 대해 AI 요약을 요청할 수 있는 API가 추가되었습니다 (Google Gemini 사용).
- ⚠️ 아직 실제 첨부파일 내용을 읽어오는 기능이 없어서, 지금 생성되는 요약은 진짜 파일 내용을 요약한 게 아닙니다. Gemini 연동 자체가 되는지 확인하는 용도로만 사용해주세요. 실제 파일 내용 연동은 후속 작업입니다.

자세한 내용은 [REVISION.md](REVISION.md)를 참고해주세요. 🤖

## 2026-08-04 · Web Push 알림 백엔드 준비 🔔

- 결재 승인으로 다음 차례가 된 사람에게 나중에 푸시 알림을 보낼 수 있도록, 서버 내부 준비 작업을 했습니다.
- 브라우저 알림 구독 정보를 저장/해지하는 API가 추가되었습니다.
- ⚠️ 아직 실제로 알림이 발송되지는 않습니다. 프론트 쪽 준비(브라우저 알림 권한, 서비스워커)가 끝나야 실제 발송까지 연결됩니다.

자세한 내용은 [REVISION.md](REVISION.md)를 참고해주세요. 🔔

## 2026-08-04 · 저장 시각을 한국 시간(KST)으로 고정 🕒

- 결재 템플릿/문서를 만들거나 승인·반려·재상신할 때 기록되는 시각이, 서버가 실행되는 환경(UTC)에 영향받지 않고 항상 한국 시간으로 저장되도록 고쳤습니다.
- API 응답 형식(필드 구조)은 달라지지 않지만, 실제 시각 값은 이전(UTC 기준으로 잘못 기록되던 값)보다 9시간 뒤로 보정되어 표시됩니다. 이번 수정이 의도한 정정입니다.

자세한 배경은 [REVISION.md](REVISION.md)를 참고해주세요. 🕒

## 2026-08-03 · 데이터 격리 강화 및 재상신 버그 수정 🔒

- 반려된 결재를 여러 번 재상신해도 새 문서가 계속 생기던 버그를 고쳤습니다. 이제 1건당 1회만 재상신됩니다.
- 다른 학원의 결재 템플릿이 목록에 섞여 보이거나, 다른 학원 템플릿으로 결재를 신청할 수 있던 문제를 막았습니다.

자세한 검증 내용은 [REVISION.md](REVISION.md)를 참고해주세요. 📚

## 2026-08-03 · 다중 파일 첨부 및 부가 기능 3종 추가 ✨

- 결재 신청 시 첨부파일을 하나가 아니라 여러 개 붙일 수 있게 되었습니다.
- 반려된 결재를 같은 내용으로 다시 신청(재상신)할 수 있습니다.
- 결재 템플릿 목록에서 결재 담당자 이름을 바로 확인할 수 있습니다.
- 사이드바에 표시할 "결재 대기 건수"를 가볍게 조회하는 API가 추가되었습니다.
- (참고) AI가 첨부파일 내용을 요약해주는 기능은 데이터베이스 칸만 미리 만들어 뒀고, 실제 요약 기능은 아직 동작하지 않습니다.

🔎 설계 배경은 [REVISION.md](REVISION.md)에서 확인할 수 있습니다.

## 2026-08-01 · DB 컬럼/테이블 팀 컨벤션 정합화 ⚙️

- 여러 학원이 함께 쓰는 구조에 맞게, 결재 템플릿·문서에 소속 학원 정보가 추가되었습니다.

## 2026-07-31 · 결재 템플릿/문서 분리 🧭

- "결재 틀(템플릿)"과 "실제 결재 신청 1건(문서)"이 명확히 분리되었습니다. 이제 행정직원이 템플릿을 미리 만들어두면, 직원·강사가 그 템플릿을 골라 결재를 신청하는 구조입니다.
- 순서대로 결재하는 로직(1차 승인 전엔 2차가 처리 못 함)이 반영되었습니다.
