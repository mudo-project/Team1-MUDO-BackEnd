## 2026-08-03 · 공지사항 기능 최초 추가 ✨

- 공지사항 작성/목록조회/상세조회/수정/삭제 기능이 추가되었습니다.
- 공지를 상단에 고정하거나 고정을 해제할 수 있습니다.

- 다른 학원의 공지는 보이지 않도록 처음부터 분리했습니다. 🔒
- (참고) 공지 카테고리(인사/시설/업무) 분류 기능은 이번에는 포함되지 않았습니다.
