# Notion "API 명세서" 데이터베이스 행(Row) — 전자결재

> 스크린샷의 표(EPIC / SUB-EPIC / API 명칭 / 엔드포인트 / 메서드 / 사용 계층 / 우선순위 / 설명) 컬럼에 그대로 채워 넣을 값들입니다.
> `API 명칭`이 각 행의 제목("열기" 버튼으로 들어가는 하위 페이지)이 되고, 그 하위 페이지 본문은 `approval_api_spec.md`의 같은 번호 섹션을 그대로 붙여넣으면 됩니다.
> - `사용 계층`: 실제 구현된 권한 제한 기준 — 현재 역할(role) 기반 접근 제어가 아직 붙지 않아 인증된 사용자면 전부 접근 가능하므로 전 행이 `전체`입니다 (작성자 본인/신청자 본인 등 소유권 검증은 별도로 있으나 "계층"과는 다른 성격이라 설명 칸에 표기).
> - `우선순위`: 팀에서 직접 판단해 채우도록 비워뒀습니다.

| EPIC | SUB-EPIC | API 명칭 | 엔드포인트 | 메서드 | 사용 계층 | 우선순위 | 설명 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 전자결재 | 템플릿 | 결재 템플릿 생성 | `/api/approval-templates` | POST | 전체 | | 이름과 기본 결재선(순서 있는 담당자 목록)을 지정해 템플릿을 만든다. |
| 전자결재 | 템플릿 | 결재 템플릿 목록조회 | `/api/approval-templates` | GET | 전체 | | 요청자 소속 학원의 템플릿만 페이지 단위로 조회한다. 결재선 담당자 이름 포함. |
| 전자결재 | 템플릿 | 결재 템플릿 상세조회 | `/api/approval-templates/{templateId}` | GET | 전체 | | 템플릿 1건의 이름·결재선을 상세 조회한다. |
| 전자결재 | 템플릿 | 결재 템플릿 수정 | `/api/approval-templates/{templateId}` | PATCH | 전체 | | 이름·결재선을 요청 값으로 전체 교체한다. (작성자 제한은 미구현, 소속 학원 검증만 있음) |
| 전자결재 | 템플릿 | 결재 템플릿 삭제 | `/api/approval-templates/{templateId}` | DELETE | 전체 | | 템플릿을 삭제한다. (작성자 제한은 미구현, 소속 학원 검증만 있음) |
| 전자결재 | 결재문서 | 결재 신청 | `/api/approvals` | POST | 전체 | | 템플릿을 선택해 결재를 신청한다. 다중 파일 첨부 가능. |
| 전자결재 | 결재문서 | 내게 온 결재 목록조회 | `/api/approvals/me` | GET | 전체 | | 내가 결재선에 포함된 결재 문서 목록을 페이지 단위로 조회한다. |
| 전자결재 | 결재문서 | 내가 신청한 결재 목록조회 | `/api/approvals/me/submitted` | GET | 전체 | | 내가 신청자인 결재 문서 목록을 페이지 단위로 조회한다. |
| 전자결재 | 결재문서 | 결재 대기 건수 조회 | `/api/approvals/me/pending-count` | GET | 전체 | | 내가 현재 차례(PENDING)인 진행중 결재 건수만 조회한다 (사이드바 뱃지용). |
| 전자결재 | 결재문서 | 결재 상세조회 | `/api/approvals/{documentId}` | GET | 전체 | | 결재 문서 1건을 상세 조회한다. 신청자 본인 또는 결재선 포함자만 가능(그 외 403). |

| 전자결재 | 웹푸시 | 푸시 구독 해지 | `/api/approvals/push-subscriptions` | DELETE | 전체 | | 본인 구독만 해지할 수 있다. |
