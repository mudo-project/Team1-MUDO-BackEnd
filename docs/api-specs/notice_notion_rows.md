# Notion "API 명세서" 데이터베이스 행(Row) — 공지사항

> 스크린샷의 표(EPIC / SUB-EPIC / API 명칭 / 엔드포인트 / 메서드 / 사용 계층 / 우선순위 / 설명) 컬럼에 그대로 채워 넣을 값들입니다.
> `API 명칭`이 각 행의 제목("열기" 버튼으로 들어가는 하위 페이지)이 되고, 그 하위 페이지 본문은 `notice_api_spec.md`의 같은 번호 섹션을 그대로 붙여넣으면 됩니다.
> - `사용 계층`: 실제 구현된 권한 제한 기준 — 현재 역할(role) 기반 접근 제어가 아직 붙지 않아 인증된 사용자면 전부 접근 가능하므로 전 행이 `전체`입니다 (작성자 본인 등 소유권 검증은 별도로 있으나 "계층"과는 다른 성격이라 설명 칸에 표기).
> - `우선순위`: 팀에서 직접 판단해 채우도록 비워뒀습니다.
