# Notion "API 명세서" 데이터베이스 행(Row) — 개인메모

> 표(EPIC / SUB-EPIC / API 명칭 / 엔드포인트 / 메서드 / 사용 계층 / 우선순위 / 설명) 컬럼에 그대로 채워 넣을 값들입니다.
> `API 명칭`이 각 행의 제목("열기" 버튼으로 들어가는 하위 페이지)이 되고, 그 하위 페이지 본문은 `memo_api_spec.md`의 같은 번호 섹션을 그대로 붙여넣으면 됩니다.
> - `사용 계층`: 역할(role) 기반 접근 제어가 붙지 않아 인증된 사용자면 전부 접근 가능하므로 전 행이 `전체`입니다(본인 소유 메모만 조회·수정 가능한 소유권 검증은 별도로 있음).
> - `우선순위`: 팀에서 직접 판단해 채우도록 비워뒀습니다.
