# 프론트 백엔드 연동 환경 실행

프론트 팀원이 백엔드 소스, IntelliJ, Java, Gradle, MySQL 또는 AWS CLI 없이 Docker Desktop만으로 백엔드 연동 환경을 실행하는 절차다.

## 백엔드 담당자 최초 설정

1. Docker Hub에 `mudo-groupware-backend` 저장소를 만든다.
2. 프론트 팀원이 로그인 없이 이미지를 받게 하려면 저장소를 Public으로 설정한다.
3. GitHub 저장소의 `Settings → Secrets and variables → Actions`에 다음 Repository Secret을 등록한다.

| Secret | 값 |
|---|---|
| `DOCKERHUB_USERNAME` | Docker Hub 사용자 또는 조직 이름 |
| `DOCKERHUB_TOKEN` | Docker Hub에서 발급한 Push용 Access Token |

4. `develop` 브랜치에 코드가 머지되면 `publish-develop-image.yml`이 테스트 후 이미지를 게시한다.

게시되는 태그:

```text
<DOCKERHUB_USERNAME>/mudo-groupware-backend:develop
<DOCKERHUB_USERNAME>/mudo-groupware-backend:<Git 커밋 SHA>
```

현재 애플리케이션 코드가 컴파일 또는 테스트에 실패하면 이미지는 게시되지 않는다. 최신 `develop` 코드 병합 후 워크플로가 성공하는지 확인한다.

## 프론트 저장소에 공유할 파일

다음 두 파일을 프론트 저장소의 같은 디렉터리에 복사한다.

```text
docker-compose.integration.yml
.env.backend.example
```

## 프론트 팀원 최초 실행

Docker Desktop을 실행한 뒤 환경변수 파일을 만든다.

```powershell
Copy-Item .env.backend.example .env.backend
```

`.env.backend`의 `BACKEND_IMAGE`를 실제 Docker Hub 이미지로 변경하고 나머지 비밀번호와 JWT 시크릿을 개인 로컬 값으로 변경한다.

```dotenv
BACKEND_IMAGE=<DOCKERHUB_USERNAME>/mudo-groupware-backend:develop
LOCAL_MYSQL_ROOT_PASSWORD=<개인 로컬 값>
DB_USERNAME=mudo_app
DB_PASSWORD=<개인 로컬 값>
JWT_SECRET=<개인 로컬 값>
```

실행한다.

```powershell
docker compose --env-file .env.backend -f docker-compose.integration.yml up -d
```

`pull_policy: always` 설정으로 인해 실행할 때마다 최신 `develop` 이미지가 있는지 확인한다.

상태와 백엔드 응답을 확인한다.

```powershell
docker compose --env-file .env.backend -f docker-compose.integration.yml ps
Invoke-RestMethod http://localhost:8080/actuator/health
```

프론트 애플리케이션의 API 주소는 다음으로 설정한다.

```dotenv
VITE_API_BASE_URL=http://localhost:8080
```

## 최신 백엔드 반영

```powershell
docker compose --env-file .env.backend -f docker-compose.integration.yml pull app
docker compose --env-file .env.backend -f docker-compose.integration.yml up -d app
```

## 로그 및 종료

```powershell
# 백엔드 로그
docker compose --env-file .env.backend -f docker-compose.integration.yml logs -f app

# 종료하되 로컬 DB 데이터는 유지
docker compose --env-file .env.backend -f docker-compose.integration.yml down
```

DB까지 완전히 초기화할 때만 다음 명령을 사용한다.

```powershell
docker compose --env-file .env.backend -f docker-compose.integration.yml down -v
```
